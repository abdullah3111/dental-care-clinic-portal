# Dental Care - Clinic & Patient Appointment Portal

A clean, modern, and responsive healthcare web application designed for dental clinics, dental surgeons, and patient care management.

## ✨ Key Features
- **Clinic Overview & Services**: Comprehensive treatment catalog (Cosmetic Dentistry, Orthodontics, Dental Implants, Teeth Whitening, Pediatric Care).
- **Specialist Doctor Profiles**: Detailed practitioner biographies, specializations, credentials, and consultation hours (`doctor-profile.html`).
- **Interactive Appointment Booking**: Easy-to-use patient consultation inquiry and scheduling form (`contact.html`).
- **Modular Component Architecture**: Reusable header, footer, and navigation components (`navbar.html`, `footer.html`).
- **Mobile-Responsive Design**: Tailored layout for smartphones, tablets, and desktop displays.

## 📁 Project Structure
- `home.html` - Clinic landing page with service highlights
- `about.html` - Clinic mission, history, and healthcare team
- `services.html` - Full catalog of dental procedures and care plans
- `doctor-profile.html` - Detailed practitioner profiles and expertise
- `contact.html` - Contact information, interactive map, and inquiry form
- `styles.css` / `navbar.css` / `footer.css` - Modular stylesheet hierarchy
- `assets/` - High-resolution clinic imagery, medical icons, and branding

## 🚀 Getting Started
Clone the repository and open `home.html` in any modern web browser:
```bash
git clone https://github.com/abdullah3111/dental-care-clinic-portal.git
cd dental-care-clinic-portal
# Open home.html in your browser
```
