# MediCare Clinic - User Profile System

## Overview
Complete user profile system with airpods-style dark theme design for MediCare Clinic. Built with HTML, CSS, and JavaScript.

## Pages
1. **Profile (index.html)** - Main user profile with personal information and security settings
2. **Appointments (appointments.html)** - View and manage medical appointments
3. **Medical Records (medical-records.html)** - Access medical history and records
4. **Prescriptions (prescriptions.html)** - Manage medications and pharmacy information
5. **Health Reports (health-reports.html)** - View health analytics, trends, and doctor recommendations

## Features
- **Dark Theme Design** - Airpods-inspired sleek interface with Inter font
- **Responsive Navigation** - Top navigation bar and sidebar menu
- **Interactive Elements** - All buttons, cards, and links are functional with medical-themed notifications
- **Medical Notifications** - Custom healthcare-themed messages and confirmations
- **Seamless Navigation** - Smooth transitions between pages with loading indicators
- **User-Friendly Interface** - Intuitive design with proper visual feedback

## Navigation Structure
- Top navigation: Quick access to all main pages
- Sidebar navigation: Detailed menu with user stats and profile information
- Consistent navigation across all pages
- Current page highlighting and proper state management

## Technical Details
- **Frontend Only** - No backend functionality required
- **Modern CSS** - Flexbox, Grid, and CSS variables
- **Vanilla JavaScript** - No external dependencies
- **Font Awesome Icons** - Medical and UI icons
- **Google Fonts** - Inter font family for modern typography

## Usage
1. Open any HTML file in a web browser
2. Navigate between pages using top navigation or sidebar
3. All interactive elements provide visual feedback
4. Medical-themed notifications guide user actions

## Design Theme
- **Primary Color**: #2989d8 (Medical Blue)
- **Background**: #0a0a0a (Deep Black)
- **Cards**: #111 (Dark Gray)
- **Text**: White/Gray variants
- **Accent**: Various medical-themed colors for status indicators

All pages maintain consistent design language and user experience patterns.
